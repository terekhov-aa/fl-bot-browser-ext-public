# FL.ru Project Parser & Uploader

Chrome расширение для парсинга проектов с FL.ru и автоматической отправки данных на сервер.

## 🚀 Возможности

- ✅ Полный парсинг информации о проекте:
  - ID и URL проекта
  - Название и описание
  - Информация о заказчике
  - Бюджет (с конвертацией в доллары)
  - Категории и разделы
  - Даты публикации
  - Статус безопасной сделки
  - Отзывы фрилансеров

- 📎 Автоматическая загрузка вложений
- 🔗 Сбор всех ссылок из описания проекта
- 📤 Отправка всех данных на ваш сервер
- ⚙️ Настраиваемый endpoint для отправки данных
- 🔔 Уведомления о статусе операций

## 📦 Установка расширения

### Шаг 1: Подготовка файлов

1. Скачайте все файлы расширения в одну папку:
   - `manifest.json`
   - `background.js`
   - `options.html`
   - `options.js`

2. Создайте иконки (опционально) или используйте любые PNG изображения:
   - `icon16.png` (16x16 px)
   - `icon48.png` (48x48 px)  
   - `icon128.png` (128x128 px)

### Шаг 2: Установка в Chrome

1. Откройте Chrome и перейдите на страницу расширений:
   - Введите в адресной строке: `chrome://extensions/`
   - Или: Меню → Дополнительные инструменты → Расширения

2. Включите "Режим разработчика" (переключатель в правом верхнем углу)

3. Нажмите "Загрузить распакованное расширение"

4. Выберите папку с файлами расширения

5. Расширение будет установлено и активировано

## 🖥️ Установка и запуск сервера

### Требования
- Node.js (версия 14 или выше)
- npm или yarn

### Установка

1. Перейдите в папку с серверными файлами:
```bash
cd fl-parser-extension
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите сервер:
```bash
npm start
```

Сервер запустится на `http://localhost:8000`

## 🎯 Использование

### Настройка расширения

1. Кликните правой кнопкой на иконке расширения в браузере
2. Выберите "Параметры" 
3. Настройте:
   - **URL сервера** - адрес вашего сервера (по умолчанию `http://localhost:8000/api/upload`)
   - **Автоматически скачивать вложения** - включить/выключить загрузку файлов
   - **Отправлять метаданные проекта** - включить/выключить отправку информации о проекте

4. Нажмите "Сохранить настройки"
5. Используйте кнопку "Тест соединения" для проверки связи с сервером

### Парсинг проекта

1. Откройте страницу проекта на FL.ru (например: `https://www.fl.ru/projects/12345/...`)

2. Кликните правой кнопкой мыши в любом месте страницы

3. В контекстном меню выберите **"Парсить проект и отправить на сервер"**

4. Расширение:
   - Соберет всю информацию о проекте
   - Скачает все вложения
   - Отправит данные на ваш сервер
   - Покажет уведомление о результате

## 📊 Формат отправляемых данных

Данные отправляются как `multipart/form-data` со следующей структурой:

### Поле `projectData` (JSON):
```json
{
  "id": "12345",
  "url": "https://www.fl.ru/projects/12345/...",
  "title": "Название проекта",
  "customer": "Имя заказчика",
  "customerRegistration": "3 года на сайте",
  "budget": {
    "text": "5000 ₽",
    "value": 55.5
  },
  "safeDeal": true,
  "description": "Полное описание проекта...",
  "sections": "Программирование, Веб-разработка",
  "publishedDate": "15 минут назад",
  "reviews": "23 отзыва",
  "links": [
    {
      "url": "https://example.com",
      "text": "Пример сайта"
    }
  ],
  "parsedAt": "2024-01-15T10:30:00.000Z"
}
```

### Поле `files[]` (бинарные файлы):
Массив файлов-вложений из проекта

## 🛠️ Разработка

### Структура проекта
```
fl-parser-extension/
├── manifest.json       # Манифест расширения
├── background.js       # Service Worker (основная логика)
├── options.html        # Страница настроек
├── options.js          # Логика страницы настроек
├── server.js          # Node.js сервер
├── package.json       # Зависимости сервера
└── README.md          # Документация
```

### API сервера

#### POST `/api/upload`
Принимает данные проекта и файлы.

**Request:**
- Content-Type: `multipart/form-data`
- Body:
  - `projectData`: JSON с информацией о проекте
  - `files[]`: массив файлов

**Response:**
```json
{
  "status": "success",
  "message": "Data received successfully",
  "project": {
    "id": "12345",
    "title": "Название проекта",
    "filesReceived": 3,
    "savedTo": "/path/to/uploads/project_12345_1234567890"
  }
}
```

#### GET `/api/stats`
Возвращает статистику загруженных проектов.

**Response:**
```json
{
  "totalProjects": 10,
  "projects": ["project_12345_1234567890", "project_67890_1234567891"]
}
```

## 🐛 Отладка

1. **Консоль расширения:**
   - Откройте `chrome://extensions/`
   - Найдите расширение
   - Нажмите "Service Worker" → откроется консоль разработчика

2. **Логи сервера:**
   - Все операции логируются в консоль
   - Проверьте папку `uploads/` для сохраненных файлов

## 📝 Примечания

- Расширение работает только на страницах проектов FL.ru
- Максимальный размер файла: 100 MB
- Максимум файлов за раз: 50
- Сервер создает отдельную папку для каждого проекта
- Метаданные сохраняются в файл `project_metadata.json`

## 🔒 Безопасность

- Расширение запрашивает минимально необходимые разрешения
- Данные отправляются только на указанный вами сервер
- Рекомендуется использовать HTTPS для production
